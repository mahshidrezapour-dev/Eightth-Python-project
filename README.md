# Library Management System

A Python-based library management system.

## Features

- Add new books to the library
- Display all books
- Search for books by title, author, or publication year
- Delete books that are not currently borrowed
- Borrow books with borrowing period validation
- Return borrowed books
- Calculate overdue days
- Maintain borrowing history
- Track the number of times each book has been borrowed
- Validate book information and borrower details

## Technologies

- Python
- `datetime`
